# Athena Development Roadmap & Action Items

## Active Phases

- [x] **Phase 1: Agent Runtime**
  - [x] Authoritative `RunState` model with explicit lifecycle (`queued` -> `running` -> `completed`/`failed`/`cancelled`)
  - [x] Sub-agent tree hierarchy (`runId`, `parentRunId`, `rootRunId`)
  - [x] Typed `AgentEvent` stream (`AgentEventEmitter`)
  - [x] Cooperative cancellation (`CancellationTokenSource`)
  - [x] Run state and event persistence in SQLite (`runs`, `run_events`)
  - [x] Multi-resource budget model (time, tool calls, turns, tokens)
  - [x] Idempotency keys on side-effect tool calls
  - [x] Interrupted run resumption (`agent.resumeRun(runId)`)
  - [x] CLI integration (`/runs`, `/resume`, graceful `Ctrl+C` cancellation)
  - [x] Comprehensive test suite (`npm run test:runtime` - 6/6 tests passing)

- [x] **Phase 2: Context + Memory**
