# Athena Development Roadmap & Action Items

## Active Phases

- [x] **Phase 1: Agent Runtime**
  - [x] Authoritative `RunState` model with explicit lifecycle (`queued` -> `running` -> `completed`/`failed`/`cancelled`)
  - [x] Sub-agent tree hierarchy (`runId`, `parentRunId`, `rootRunId`)
  - [x] Typed `AgentEvent` stream (`AgentEventEmitter`)
  - [x] Cooperative cancellation (`CancellationTokenSource`)
  - [x] Run state and event persistence in SQLite (`runs`, `run_events`)
  - [x] Multi-resource budget model (time, tool calls, turns, tokens)
  - [x] Idempotency keys on side-effect tool calls
  - [x] Interrupted run resumption (`agent.resumeRun(runId)`)
  - [x] CLI integration (`/runs`, `/resume`, graceful `Ctrl+C` cancellation)
  - [x] Comprehensive test suite (`npm run test:runtime` - 6/6 tests passing)

- [x] **Phase 2: Context + Memory**
  - [x] Context Engine prompt pipeline (`src/core/contextEngine.ts`)
  - [x] Multi-scope memory (`global`, `user`, `workspace`, `project`, `session`, `task`)
  - [x] Memory provenance metadata & confidence scoring
  - [x] Memory lifecycle states & contradiction resolution (`supersededBy`, `supersedes`)
  - [x] User memory controls (`/memory inspect/scopes/forget/purge`)
  - [x] Budget-aware context sizing & truncation
  - [x] Skill registry success rate tracking & versioning
  - [x] Comprehensive test suite (`npm run test:context_memory` - 7/7 tests passing)

- [x] **Phase 3: Tool Runtime**
  - [x] Standardized `ToolResult` envelope (`src/core/toolRuntime.ts`)
  - [x] Central timeout policy & circuit breakers (`CircuitBreaker`, `CircuitBreakerRegistry`)
  - [x] Semantic JSON schema validation (`validateArguments`)
  - [x] Output offloading for large payloads (`scratch/artifacts/`)
  - [x] Intent-based relevant tool retrieval (`ToolSelector`)
  - [x] Comprehensive test suite (`npm run test:tools` - 8/8 tests passing)

- [ ] **Phase 4: Adaptive Orchestration**
  - [ ] Simple vs complex task routing
  - [ ] Dynamic escalation: direct loop -> planner -> specialist -> verifier
  - [ ] Self-repair loops for verification failures

- [ ] **Phase 5: Coding Harness Integration**
  - [ ] Typed `CodingTaskRequest` / `CodingTaskResult` protocol
  - [ ] Shared run IDs across Athena -> Harness
  - [ ] Zero duplication of sandbox / checkpoints / git diffs

- [ ] **Phase 6: Background + Event Runtime**
  - [ ] Persistent scheduler & timezone support
  - [ ] Job leases / locks
  - [ ] Event bus & background worker pool

- [ ] **Phase 7: Reliability + Security**

- [ ] **Phase 8: Observability + Evaluation**

  - [ ] Adversarial evaluation benchmarks

- [ ] **Phase 9: Platform / Production**
